# ProductStoreApp

An offline-first marketplace app built using SwiftUI, SwiftData, and Swift Concurrency.

## Features

- Browse and view product details
- Add new products with PhotosPicker
- Favorite/unfavorite products
- Offline local persistence using SwiftData
- Favorite synchronization
- Memory and disk image caching
- Network availability monitoring
- Support for 200+ products
- MVVM + Repository architecture
- Dependency Injection
- Unit tests with mock dependencies
- SwiftLint integration

## Tech Stack

- Swift
- SwiftUI
- SwiftData
- Swift Concurrency
- MVVM
- Repository Pattern
- REST API
- NSCache
- XCTest
- SwiftLint
